# Scientific_calcu.py
🧮 Scientific Calculator (Python)A full-featured, high-precision Scientific Calculator application built with Python. Designed to perform both basic arithmetic operations and advanced mathematical calculations, including trigonometric functions, logarithms, exponents, and statistical operations.✨ Features➕ Basic Arithmetic: Addition, subtraction, multiplication, division, modulo, and percentage.📐 Trigonometric Functions: Sine, Cosine, Tangent (and their inverses: $\arcsin$, $\arccos$, $\arctan$) supporting both Degrees and Radians.📈 Logarithm & Exponentials: Natural log ($\ln$), $\log_{10}$, custom base logarithms, $e^x$, and $x^y$.🔢 Advanced Math: Square root ($\sqrt{x}$), $n$-th root, factorials ($n!$), absolute value, and powers.📊 Memory Functions: Memory Save ($MS$), Memory Recall ($MR$), Memory Add ($M+$), Memory Subtract ($M-$), and Memory Clear ($MC$).🔣 Mathematical Constants: Direct access to $\pi$ (Pi) and $e$ (Euler's number).🛑 Error Handling: Built-in validation for division-by-zero, negative roots, and domain errors with clear user feedback.🛠️ Built WithPython 3.x - Core programming language.math - Standard library for underlying mathematical algorithms.tkinter (or PyQt/CLI) - Graphical User Interface for desktop interaction.
